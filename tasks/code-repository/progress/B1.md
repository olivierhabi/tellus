## 2. Why this isn't started in this session

`D-2026-05-01-001`: spinning up testcontainers (Postgres + MinIO + a Kafka for
B10 hook events + Compass + Multipass + OMS) without your explicit go-ahead is
imprudent on a developer machine; running the chaos suite (N=50 concurrent
git pushes, 1 GB packfiles, k6 windows of 30 minutes) burns local resources
without a defined quit signal; and falsely stamping B1 DONE without those
suites green is the audit-gap hard stop.

When you greenlight a wave-by-wave cadence, the agent that picks up Wave 1
opens this file, reads §1.4–§1.6, runs `tests/integration/stemma/_helpers/
spawn-stemma.ts` which brings up the testcontainer fleet, and proceeds.
