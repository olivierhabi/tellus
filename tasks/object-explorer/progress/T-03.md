## Rubric items satisfied
- **Input validation:** `ontologyId` and `sql` non-empty string checks
  at route boundary; `SQL_MAX_QUERY_LENGTH` at service boundary;
  `enforceReadOnly` keyword classification.
- **Timeouts on every downstream call:** `SQL_STATEMENT_TIMEOUT_MS` on
  user SQL execution; OpenSearch search call inherits the existing
  `withRetry` deadline path (not introduced here).
- **Bounded queues / pagination caps:** `SQL_ROW_LIMIT` injected via
  `injectLimit`; `FURNACE_SAMPLE_LIMIT` clamped to `[1000, 50000]`.
- **Structured logs with correlation IDs:** route uses `sendError`
  which embeds `requestId` from the canonical envelope.
- **RED metrics + domain metrics:**
  - `tellus_sql_query_duration_seconds{outcome}` (histogram)
  - `tellus_sql_query_total{outcome}` (counter)
  - `tellus_sql_cache_hits_total{result}` (counter)
  - `tellus_sql_invalidate_total{by_role}` (counter)
  - `tellus_sql_sandbox_set_failed_total{flag}` (counter)
- **CBAC at the data layer:** the cache key now includes a fingerprint
  of `buildSecurityFilter(ctx)` so two callers with different markings
  cannot share a snapshot. The `buildDb` body itself is wrapped in
  `applyContextToBody`, enforcing markings/CBAC/branch on every
  per-object-type OpenSearch search.
- **Branch context propagated end-to-end:** `readBranchHeader(req)` →
  cache key → `applyContextToBody` body shape.
