# T-04 — Branch-aware writeback overlay

## Contracts touched
C-50, C-51, C-52, C-53, C-54, C-55, C-56, C-57, C-58, C-59, plus
parse-helper coverage from C-49.

## Files changed
- `src/services/overlay/overlayStore.ts` — `OverlayRecord.branchId` required;
  3-arg `overlayKey`; new `legacyOverlayKey`; `parseOverlayKey` distinguishes
  new vs legacy; `MAIN_BRANCH_SENTINEL`, `isDualWriteEnabled`,
  `isLegacyReadEnabled`.
- `src/services/overlay/writebackOverlay.ts` — new `writeOverlay` with CAS,
  `readOverlay` with branch-aware fallback; `applyOverlayToResults` and
  `collectFilterMatchingOverlays` accept `branchId`; `mergeOverlayIntoSearch`
  threads `branchId` end-to-end.
- `src/services/overlay/sweeper.ts` — overlay deletion uses 3-arg key with
  `rec.branchId`.
- `src/routes/funnel.ts` — `/funnel/overlay/:objectType/:pk` reads through
  `readOverlay`; resolves `branchId` from the standard branch header.
- `src/routes/objects.ts` — `mergeWithOverlay` accepts `branchId`; all
  three callers thread it; index-miss path uses `readOverlay`.
- `src/services/funnel/metrics.ts` — added
  `tellus_overlay_branch_mismatch_total` help string.
- `vitest.unit.config.ts` — included `tests/funnel/unit/**/*-unit.test.ts`
  so the existing B7 overlay suite runs in the offline lane.

flags. See D-2026-04-30-008 for the 4-phase rollout plan.

## Rubric items satisfied
- **CBAC/Markings at the data layer**: branch-context propagation through
  `applyOverlayToResults`/`collectFilterMatchingOverlays`/`readOverlay`.
- **Branch context propagated end-to-end**: every read call site
  (`/funnel/overlay/:ot/:pk`, single-GET in `objects.ts`,
  `mergeWithOverlay`, sweeper) threads `branchId`.
- **Structured metrics**: `tellus_overlay_reads_total{branch_match,
  source}`, `tellus_overlay_writes_total{outcome}`,
  `tellus_overlay_legacy_hits_total`,
  `tellus_overlay_branch_mismatch_total` — emitted at the documented
  points; help strings live in `src/services/funnel/metrics.ts`.
- **Fail-loud over fail-silent**: CAS conflict throws
  `OVERLAY_VERSION_CONFLICT` (mappable to HTTP 409).
- **Reversibility**: rollout is phase-gated by env flags; any phase can
  roll back without redeploy.
