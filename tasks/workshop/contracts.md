# Workshop Contract Enumeration

> Generated by the Starting Protocol of the Workshop Implementation Drive (date: 2026-05-03).
> Each contract ID has the form `T-XX C-YY`. Tests reference these IDs in their names: `T-XX C-YY: <observable behavior>`.
> Source-of-truth is `tasks/workshop/workshop-tasks.md`. When the spec is silent, see `decisions/workshop/`.

Conventions applied to every B-task unless overridden:

- **§0.1** Conjure-style error envelope `{ errorCode, errorName: "Tellus:Workshop:<PascalCase>", errorInstanceId: <uuid v4>, parameters }`
- **§0.2** ETag scheme `W/"<sha256(definition_jsonb || updated_at_micros)>"` returned on every read of a mutable resource; required as `If-Match` on every PUT; missing or stale → 412 `Tellus:Workshop:ResourceVersionMismatch`
- **§0.3** `Idempotency-Key` on every state-allocating POST; `(idempotency_key, user_id, route, sha256(body))` stored 24h
- **§0.4** Metric naming: histograms `_seconds`, counters `_total`, gauges no suffix; per-RID labels forbidden — exemplars only
- **§0.5** `?branch=<branchRid>` accepted on every endpoint; forwarded verbatim on every downstream OMS/OSS/Functions/Actions call
- **§0.6** Multipass JWT bearer required; 401 on missing/expired; 403 on insufficient role; same JWT propagated to downstream services

These are referred to as `G-01` through `G-06` and inherited by every task.
