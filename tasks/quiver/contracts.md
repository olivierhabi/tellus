## Global Conventions (`G-NN` — inherited by every task)

| ID   | Contract |
|------|----------|
| G-01 | All RIDs follow `ri.tellus-quiver.main.<type>.<uuid>` where uuid is **UUIDv7** (time-ordered). DDL `CHECK (rid ~ '^ri\.tellus-quiver\.main\.[a-z-]+\.[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[0-9a-f]{4}-[0-9a-f]{12}$')`. |
| G-02 | Conjure-style error envelope on every error: `{ errorCode, errorName: "Tellus:Quiver:<PascalCase>", errorInstanceId: <uuidv4>, parameters: {...} }`. No bespoke shapes; no leaking internal exception messages. |
| G-03 | `ETag` returned on every read of a mutable resource and required as `If-Match` on every PATCH/PUT/DELETE; missing or stale → 412 `Tellus:Quiver:VersionMismatch` (errorCode `VERSION_MISMATCH`) with `parameters.currentEtag`. ETag scheme `W/"<sha256-hex of canonical-row-bytes>"`. |
| G-04 | `Idempotency-Key: <uuid>` REQUIRED on every state-allocating POST. Cached 24 h in Redis at `tellus-quiver:idempotency:<key>` → `(rid, sequence, response_bytes)`. Replay with same key + same body returns byte-identical cached response. Replay with same key + different body → 409 `Tellus:Quiver:IdempotencyKeyReplay`. |
| G-05 | Every endpoint that touches OMS/OSS/Codex/MMDP/Functions/Actions/AIP forwards the active branch via `X-Tellus-Branch: <branch>` header (or `?branch=` on GET) **verbatim** on every downstream call. A single missed forward is a Blocker. |
| G-06 | Every compute path accepts `X-Deadline: <isoInstant>`. Coordinator computes remaining budget and propagates to backends; backends that cannot meet remaining budget return `DEADLINE_EXCEEDED` (`COMPUTE_DEADLINE_EXCEEDED`) at the boundary, not at completion. |
| G-07 | Multipass JWT bearer required on every endpoint; 401 `Tellus:Quiver:Unauthenticated` on missing/expired; 403 `Tellus:Quiver:InsufficientPermission` on insufficient role. Compass `isAuthorized` and OMS `canApplyAction` checked at every resource boundary; results cached 30 s. |
| G-08 | Markings (CBAC) and Organizations (mandatory access controls) gate resource visibility **before** any business logic executes. |
| G-09 | OpenTelemetry traces with W3C `traceparent` propagation; sampler 1 % prod / 100 % dev. Witchcraft-style structured JSON logs with `traceId`, `spanId`, `userId`, `orgId`, `requestId`. Prometheus on `:7071/metrics` (or shared service exporter); histograms `_seconds`, counters `_total`, gauges no suffix; per-RID labels FORBIDDEN — exemplars only. |
| G-10 | Every mutating endpoint emits exactly one structured audit row (`tellus.quiver.<event>`) with `actor_subject`, `rid`, `before_etag`, `after_etag`, `branch`, `request_id`. |
| G-11 | Migrations under `src/migrations/` Flyway-style, ordered, additive only; `.up.sql` and `.down.sql` round-trip on the test harness; `created_at`, `updated_at`, `etag` columns on every primary table. |
| G-12 | Service-to-service calls use service-account JWTs scoped via `aud=tellus-quiver-service`. |
| G-13 | Phase feature flags (`tellus.quiver.phase1` … `tellus.quiver.phase5`) gate every endpoint per Delivery Sequencing; default off in prod, on in dev. |
