# B02 — Module Schema Validator + Variable-Graph Compiler

## What it does
Validates Workshop module documents against
`/schemas/workshop-module-v4.json` (JSON Schema 2020-12) plus nine
semantic rules (duplicate variable IDs, variable-graph cycles, orphan
widget references, dangling refs, type compatibility at every binding
edge, external-ID uniqueness, loop/embed coherence, auto-generated
active-object invariant). Compiles the variable graph to a
topologically-sorted DAG.

Service surface: `src/services/workshop/validator.ts`. Called
in-process from B01 createModule + updateModule + B03 publishVersion +
the B04 bootstrapModule path. Also exposed at `POST
/workshop/api/v1/modules/_validate` for the editor's defense-in-depth.

## Alerts

| Alert | Trigger | Severity |
|---|---|---|
| `WorkshopValidateP95High` | `histogram_quantile(0.95, ...workshop_validate_seconds...) > 0.080` for 10m | P2 |
| `WorkshopValidateAlwaysFails` | `rate(workshop_validate_total{result="invalid"}[5m]) / rate(workshop_validate_total[5m]) > 0.5` for 30m | P3 — likely a frontend bug emitting bad documents |

## Diagnose

### Symptom: VariableGraphCycle thrown but the document looks acyclic
1. Cycle detection runs against the *definition* graph, not the runtime
   evaluation graph. Events do not participate in cycles (§B02 C-12).
2. Decision **D-11**: filterByVariable's host can be objectSet OR
   objectSetFilter; check that the document's filter chain is correctly
   typed.
3. Inspect the `parameters.cyclePath` — every cycle ships its full path.

### Symptom: Schema 400 with no semantic rule firing
1. The structural schema rejected the document before semantic rules
   could run. Check `parameters.issues` for AJV-style issue paths.

## Remediate
- Schema regression → bump `schemaVersion` and write a migration that
  rewrites old documents to the new shape; never silently coerce.
- Validator perf regression → property-test the topological sort with
  `validator.test.ts:topo random DAGs`; target P95 ≤ 80ms (CPU-bound,
  single-core).

## Metrics
- `workshop_validate_seconds` (histogram)
- `workshop_validate_total{result}` (counter; `result ∈ {valid,invalid}`)
