# F06 — Filter rail runbook

## Summary
Per-uiKind Blueprint controls; emits buildFilterClauses() into filter variable

## Alerts that page on this task

Filter compile failure (UnsupportedFilterPropertyType, etc)

## Diagnose

Inspect uiKind × propertyType matrix in src/services/workshop/filterCompiler.ts; correct property type in objectType schema

## Remediate

1. Reload the editor (F01–F09) or view-mode page (F10).
2. If the issue persists, capture a HAR and the Workshop service logs (`/api/v1/health` should be healthy; `/workshop/api/v1/metrics` exposes Prometheus counters).
3. For ETag mismatch (412) cascading from F02/F05/F06/F07/F09: never auto-merge. Show the user 'your view is out of date — reload to keep editing' per spec §B01.
4. For ActionStaleObject 409 (F09/F10 apply path): never auto-retry. Surface 'reload' affordance per Forbidden Behaviors.
