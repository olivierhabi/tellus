# B05 — Object Set Load Proxy

## Surface
`POST /workshop/api/v1/object-sets/_load`. Forwards branch + JWT +
executionMode + snapshotConsistency verbatim to OSS via the
`OssAdapter` interface (`src/services/workshop/ossAdapter.ts`). Filter
clauses are compiled by B07 before reaching OSS.

## Alerts
- `WorkshopOssLoadP95High`: P95 > 800ms for `pageSize ≤ 1000`.
- `WorkshopOssRateLimitHits`: 429 rate from OSS > 1/s for 5m — likely
  a single user hot-loop in the editor.

## Diagnose
- **InvalidPageSize 400**: pageSize must be `1..MAX`. `MAX` is set in
  the route config; check `OBJECT_SET_LOAD_MAX_PAGE`.
- **Filter compilation 400 with `Tellus:Workshop:Unsupported…`**: a
  property-type / uiKind combination that B07's COMPAT matrix rejects.
  See `filterCompiler.ts:COMPAT`.

## Remediate
- OSS down: load returns 504; the editor surfaces a callout. No retry
  on the server (the user controls retry).

## Metrics
- `workshop_object_set_load_seconds`,
  `workshop_object_set_load_total{status}`.
