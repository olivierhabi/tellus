# B08 — Aggregation Proxy

## Surface
`POST /workshop/api/v1/object-sets/_aggregate`. Forwards to OSS
aggregate API. The Bar XY chart numeric-x-axis rule is the spec's
named hard rule (§B08 + §F07 + §C P5S6): default to
`fixedWidthBuckets`. Implemented in
`src/services/workshop/aggregationService.ts:applyChartKindDefaults`.

## Alerts
- `WorkshopAggregateP95High`: P95 > 1s for `PREFER_SPEED` and
  bucketCount ≤ 1000.
- `WorkshopAggregateBucketBlowup`: client requested > 10000 buckets;
  reject at the route.

## Diagnose
- **Chart shows one bar per row for a numeric axis**: the
  default-bucketing rule didn't fire. Check:
  ```
  workshop_aggregate_groupby_kind_total{kind="exact",property_type=~"integer|double"}
  ```
  This counter should be near zero — non-zero indicates a regression.
- **NoAggregationSpecified 400**: the request omitted the `aggregations`
  array. Editor bug; a chart MUST request at least one.

## Remediate
- Per-request bucket cap: configure via `WORKSHOP_AGG_MAX_BUCKETS`.
- OSS aggregate timeout: same as B05 (no auto-retry on the server).

## Metrics
- `workshop_aggregate_seconds`, `workshop_aggregate_total{status}`,
  `workshop_aggregate_groupby_kind_total{kind, property_type}`.
