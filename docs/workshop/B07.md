# B07 — Workshop Filter Compiler

## Surface
Pure CPU; no HTTP edge. Used in-process by B05 + B08.
`src/services/workshop/filterCompiler.ts` — 11 uiKinds, COMPAT matrix,
cycle detection.

## Alerts
- `WorkshopFilterCompilePerf`: P95 > 20ms — a regression in the
  COMPAT matrix or cycle DFS.

## Diagnose
- **CircularFilterReference 400**: a filter variable transitively
  references its own consumer. The error envelope's
  `parameters.cyclePath` lists the full path — usually the user
  wired a `Filter using a variable` constraint in a loop.
- **UnsupportedFilterPropertyType**: the uiKind chosen by the editor
  is not compatible with the property's OMS type. Check
  `COMPAT[uiKind]` in source.

## Remediate
- Per-keystroke pre-flight is the hot path; if perf regresses, profile
  the compatibility matrix evaluation (it should be O(1) per filter).

## Metrics
- `workshop_filter_compile_seconds` (histogram).
