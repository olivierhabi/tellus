# Runbook — Quiver B4 (Versioning + Working State)

**Owner**: Tellus Quiver team
**Spec**: `tasks/quiver/quiver-tasks.md` §B4

## Surfaces

- `POST /quiver/api/v1/analyses/:rid/versions` — saveVersion (If-Match required)
- `GET  /quiver/api/v1/analyses/:rid/versions[?namedOnly=true]` — listVersions
- `GET  /quiver/api/v1/analyses/:rid/versions/:version` — getVersion
- `POST /quiver/api/v1/analyses/:rid/versions/:version:revert` — revertToVersion (If-Match required)
- `POST /quiver/api/v1/analyses/:rid/working-states` — createWorkingState
- `PUT  /quiver/api/v1/analyses/:rid/working-states/:stateId` — upsertWorkingStateDocument
- `GET  /quiver/api/v1/analyses/:rid/working-states/:stateId` — getWorkingState
- `POST /quiver/api/v1/_admin/purge-working-states` — sweeper (cron-invoked)

## Alerts

- **QuiverSaveVersionP99Breach** — `histogram_quantile(0.99, rate(tellus_quiver_save_version_seconds_bucket[5m])) > 1` for 10 min → page on-call.
- **QuiverRevertP99Breach** — `histogram_quantile(0.99, rate(tellus_quiver_revert_seconds_bucket[5m])) > 0.5` for 10 min → page on-call.
- **QuiverWorkingStateSweeperStalled** — `rate(tellus_quiver_working_state_ttl_purges_total[1h])` is 0 AND `pg_table_row_count{table="quiver_working_state"}` > 100k for 2 h → page on-call (cron is dead).

## SOPs

1. **Sweeper cron** — invoke `POST /quiver/api/v1/_admin/purge-working-states`
   every 15 min from cluster cron; expect `200 {purged: N}`. If N grows
   unboundedly, check sweeper job logs.
2. **Stuck saveVersion** — usually contention on `quiver_analysis` row
   under FOR UPDATE; check `pg_stat_activity` for blocked sessions on
   that `rid`.
3. **`:revert` URL not matching** — Express escapes the colon; the route
   pattern is `/versions/:version\\:revert`. Curl: encode the colon as
   `%3A` if your client mangles literal `:`.
4. **stateId collisions in logs** — service retries up to 5 times.
   Sustained collisions → entropy issue with `randomBytes`; emit a SEV-3.
