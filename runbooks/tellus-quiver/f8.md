# Runbook — F8 Real-time Collaboration WebSocket Gateway

## Surface
- WebSocket endpoint `/quiver/api/v1/analyses/:rid/collab` (hand-shake guarded by Multipass JWT bearer; subprotocol `quiver-collab.v1`).
- In-process `wsGateway` subscribes to the OT eventBus and fans out applied instructions + presence events to all connected clients on a given `rid`.
- Frame types (server → client): `INSTRUCTION_APPLIED`, `PRESENCE`, `CURSOR`, `SELECTION`, `ERROR`, `PONG`.
- Frame types (client → server): `PING`, `CURSOR`, `SELECTION`, `LEAVE`.

## SLOs
- WS handshake latency p95 ≤ 200 ms (deferred to GATE-01 measurement).
- INSTRUCTION_APPLIED propagation same-region p95 ≤ 200 ms (deferred).
- Cursor/Selection update propagation p95 ≤ 200 ms (deferred).
- Reconnect storm: 100 simultaneous reconnects to one analysis without server error (verified by `f8-ws-gateway-integration` chaos block).

## Alerts (Grafana folder `tellus-quiver`)
| Alert | PromQL | Threshold | SOP |
|---|---|---|---|
| `QuiverCollabHighDisconnectRate` | `rate(tellus_quiver_ot_ws_disconnects_total[5m])` | `> 5` for 5 m | Check upstream LB idle timeout; check OT eventBus subscriber count via `tellus_quiver_ot_collab_active_sessions`. |
| `QuiverCollabSessionLeak` | `tellus_quiver_ot_collab_active_sessions` | `> 5000` | Restart the api pod that hosts the leaking sessions; investigate eventBus unsubscribe path. |
| `QuiverCollabPropagationLag` | `histogram_quantile(0.95, rate(tellus_quiver_ot_submit_seconds_bucket[5m]))` | `> 0.2 s` for 10 m | Check Postgres write latency; check OT eventBus drain. |

## Operational Notes
- The gateway holds the WebSocket -> rid mapping in memory; a horizontally-scaled replacement requires a Redis pub/sub or NATS layer (deferred per D-46; see `decisions/quiver/D-2026-05-04-f8-decisions.md`).
- Heartbeat: server sends `PONG` on every `PING`; client closes after 30 s of silence (FE-only per F8 ADR).
- Reconnect: client refetches `GET /analyses/:rid` then resumes from `lastSeq + 1` via `GET /analyses/:rid/instructions?fromSeq=…` (B3 surface).
- Authorisation: Compass `isAuthorized(read)` is checked at handshake; resource removal forces a server-initiated close with frame `{ type: "ERROR", errorName: "Tellus:Quiver:Collab:Revoked" }`.

## Rollback
- Disable Phase 3 by setting `TELLUS_QUIVER_PHASE=2` and restarting the api pods. Active sessions close cleanly (server sends LEAVE then closes).
