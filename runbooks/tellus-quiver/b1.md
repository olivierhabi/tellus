## SOPs

### "ETag mismatch storm" alert fires
1. Identify the affected resource: `kubectl logs -l app=tellus-api -c api | grep VersionMismatch | jq -s '.[].rid' | sort | uniq -c | sort -rn | head -5`.
2. Check whether one client is auto-retrying without re-fetching — the spec is explicit (F2 C-03): `OT_BASE_VERSION_TOO_OLD` clients MUST re-fetch and rebase. If a client is retrying blindly, contact the client team.
3. If the affected RID is hot-spotted across users, suspect concurrent collaborative editing (F8 reconnect storm). Drain by capping presence broadcasts.

### "Compass register failures" alert fires
1. Compass health: `curl -fsS http://compass:8080/_status/health` (or the service-mesh equivalent in your env).
2. If Compass is down, set `quiver-readonly-mode=true` in the feature-flag service to surface a clean "creation temporarily disabled" UI rather than 500s.
3. After Compass recovery, sweep for orphan rows: `SELECT rid, parent_folder_rid FROM quiver_analysis WHERE created_at > '<incident_start>' AND NOT EXISTS (SELECT 1 FROM compass_resource WHERE rid = quiver_analysis.rid);`

### "5xx rate elevated"
1. `curl http://api:7311/quiver/api/v1/analyses/<known-good-rid>` — if 401/403 it's an auth issue, not a service issue.
2. Run the verification harness: `bash scripts/quiver-verify.sh`. If it fails at stage 4 (vitest), there is a regression and the most recent deploy should be rolled back.

### Stale idempotency cache
The Postgres-backed `quiver_idempotency_record` table accumulates rows; the partial index on `expires_at` is pruned by a scheduled sweep. If sweep stops, rows live forever — disk growth alarm. SOP: run `DELETE FROM quiver_idempotency_record WHERE expires_at < now();` and verify the sweep job's last successful run timestamp.

## Recovery / rollback

* Migrations 062 and 063 are reversible. To roll back:
  1. Stop API instances behind the flag (`TELLUS_QUIVER_PHASE=0`).
  2. Apply `src/migrations/063_b1_quiver_idempotency.down.sql` then `062_b1_quiver_analysis.down.sql`.
  3. Re-deploy API at the prior build.
