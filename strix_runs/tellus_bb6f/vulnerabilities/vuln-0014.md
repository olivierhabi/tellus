## Description

The transitive package **`fast-xml-parser@5.4.1`** (pinned via `pnpm-lock.yaml` through `@aws-sdk/client-s3`) is affected by CVE-2026-41650: improper escaping of XML comments and CDATA sections enables XML injection — attacker-controlled values serialized by the parser/builder can break out of their intended context and inject arbitrary XML structure into the generated document. Fixed in `5.7.0`.

## Evidence

**Advisory evidence:** `CVE-2026-41650` applies to `fast-xml-parser` at installed version `5.4.1`. The advisory is fixed in `5.7.0`.

**Transitive dependency:** introduced by the direct dependency `@aws-sdk/client-s3@3.1010.0`.

**Dependency chain:** `@aws-sdk/client-s3@3.1010.0 > @aws-sdk/core@3.973.20 > @aws-sdk/xml-builder@3.972.11 > fast-xml-parser@5.4.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct `fast-xml-parser` import in application code; reached transitively through `@aws-sdk/client-s3` (direct dep used by the S3/MinIO storage layer). Affected-symbol (comment/CDATA escaping in the builder) check inside the SDK chain was not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

XML injection: an attacker-controlled string serialized through the XML builder (e.g. an S3 object metadata value) can inject additional XML elements/structure into the produced document, producing a low-integrity impact on the serialized output. No direct confidentiality/availability effect.

## Technical Analysis

**Root cause:** fast-xml-parser ≤ 5.6.x does not correctly escape XML comments and CDATA when serializing, allowing XML injection. Distinct mechanism from the two entity-expansion DoS CVEs on the same package.

**Dependency chain (`pnpm-lock.yaml`):** `@aws-sdk/client-s3@3.1010.0 > @aws-sdk/core@3.973.20 > @aws-sdk/xml-builder@3.972.11 > fast-xml-parser@5.4.1`.
