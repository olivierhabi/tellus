## Description

The transitive package **`fast-xml-parser@5.4.1`** (pinned via `pnpm-lock.yaml` through `@aws-sdk/client-s3`) is affected by CVE-2026-33349: unbounded XML entity expansion causes denial of service. Fixed in `5.5.7` / `4.5.5`. Distinct mechanism from the sibling CVE-2026-33036 (which bypasses the maxTotalExpansions limits).

## Evidence

**Advisory evidence:** `CVE-2026-33349` applies to `fast-xml-parser` at installed version `5.4.1`. The advisory is fixed in `5.5.7`.

**Transitive dependency:** introduced by the direct dependency `@aws-sdk/client-s3@3.1010.0`.

**Dependency chain:** `@aws-sdk/client-s3@3.1010.0 > @aws-sdk/core@3.973.20 > @aws-sdk/xml-builder@3.972.11 > fast-xml-parser@5.4.1`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct `fast-xml-parser` import in application code; reached transitively through `@aws-sdk/client-s3` (direct dep used by the S3/MinIO storage layer). Affected-symbol check inside the SDK chain was not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

Unbounded entity expansion on a crafted XML document processed through the AWS SDK XML parser causes excessive resource consumption and process-level DoS. Availability impact only.

## Technical Analysis

**Root cause:** unbounded entity expansion in fast-xml-parser ≤ 5.5.6 (this CVE) — a separate flaw from the numeric-character-reference limit bypass of CVE-2026-33036.

**Dependency chain (`pnpm-lock.yaml`):** `@aws-sdk/client-s3@3.1010.0 > @aws-sdk/core@3.973.20 > @aws-sdk/xml-builder@3.972.11 > fast-xml-parser@5.4.1`.
