## Description

Two pinned copies of **`brace-expansion`** (`1.1.12` and `2.1.0`) are affected by CVE-2026-69152: unbounded intermediate arrays cause DoS, bypassing the earlier CVE-2026-14257 mitigation. Fixed in `1.1.18` / `2.1.4` / `3.0.6` / `5.0.9`.

## Evidence

**Advisory evidence:** `CVE-2026-69152` applies to `brace-expansion` at installed version `1.1.12`. The advisory is fixed in `1.1.18`.

**Transitive dependency:** introduced by the direct dependency `duckdb@1.4.4`.

**Dependency chain:** `duckdb@1.4.4 > node-gyp@9.4.1 > glob@7.2.3 > minimatch@3.1.5 > brace-expansion@1.1.12`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct import; two pinned copies (1.1.12 + 2.1.0) under direct dep `duckdb@1.4.4`. Affected-symbol check not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

Unbounded intermediate arrays cause memory/CPU DoS in `expand()`, in the duckdb build toolchain path. Availability impact.

## Technical Analysis

**Root cause:** unbounded intermediate arrays bypassing the CVE-2026-14257 mitigation. **Copies:** 1.1.12 and 2.1.0 both under duckdb's build chain. **Trivy:** Severity=HIGH, CVSS 7.5.
