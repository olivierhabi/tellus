## Description

The transitive package **`protobufjs@7.6.2`** (via `@opentelemetry/sdk-node` → `@grpc/proto-loader`) is affected by CVE-2026-54269: a name collision with a runtime identifier in generated protobuf code causes denial of service. Fixed in `7.6.3` / `8.6.0`.

## Evidence

**Advisory evidence:** `CVE-2026-54269` applies to `protobufjs` at installed version `7.6.2`. The advisory is fixed in `7.6.3`.

**Transitive dependency:** introduced by the direct dependency `@opentelemetry/sdk-node@0.218.0`.

**Dependency chain:** `@opentelemetry/sdk-node@0.218.0 > @opentelemetry/exporter-trace-otlp-grpc@0.218.0 > @grpc/grpc-js@1.14.4 > @grpc/proto-loader@0.8.0 > protobufjs@7.6.2`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct `protobufjs` import in src; reached via `@opentelemetry/sdk-node` (initialized in src/otelBootstrap.ts). Affected-symbol check not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

Name collision with a runtime identifier in generated protobuf code triggers DoS in the OTLP gRPC exporter. Low availability impact.

## Technical Analysis

**Root cause:** runtime-identifier name collision DoS in protobufjs < 7.6.3/8.6.0. **Chain:** `@opentelemetry/sdk-node@0.218.0 > @grpc/grpc-js@1.14.4 > @grpc/proto-loader@0.8.0 > protobufjs@7.6.2`. **Trivy:** Severity=MEDIUM, CVSS 5.3.

## Remediation

Resolve `protobufjs@>=7.6.5` (covers both CVE-2026-59877 and this) via `@opentelemetry` bump or `pnpm.overrides: { "protobufjs@7 <7.6.5": "^7.6.5" }`. Regenerate lockfile, verify.
