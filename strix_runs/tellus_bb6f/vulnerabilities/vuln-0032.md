## Description

The pinned copy **`brace-expansion@1.1.12`** is affected by CVE-2026-33750: a zero step value in a brace pattern causes an infinite loop / denial of service. Fixed in `1.1.13` / `2.0.3` / `3.0.2` / `5.0.5`. Reached via `minimatch` under `glob`, through `duckdb`'s build chain.

## Evidence

**Advisory evidence:** `CVE-2026-33750` applies to `brace-expansion` at installed version `1.1.12`. The advisory is fixed in `1.1.13`.

**Transitive dependency:** introduced by the direct dependency `duckdb@1.4.4`.

**Dependency chain:** `duckdb@1.4.4 > node-gyp@9.4.1 > glob@7.2.3 > minimatch@3.1.5 > brace-expansion@1.1.12`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct import; pinned copy 1.1.12 under direct dep `duckdb@1.4.4`. Affected-symbol check not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

Zero-step brace pattern causes an infinite loop / CPU DoS in the duckdb build toolchain path. Availability impact.
