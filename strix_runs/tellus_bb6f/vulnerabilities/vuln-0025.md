## Description

The transitive package **`protobufjs@7.6.2`** (pinned via `pnpm-lock.yaml` through `@opentelemetry/sdk-node` → `@grpc/proto-loader`) is affected by CVE-2026-59877: option names are parsed by advancing through schema tokens until an `=` token is reached without checking for end of input, so a crafted `.proto` schema that opens an option declaration and ends prematurely makes `Root.load`/`Root.loadSync` loop indefinitely. Fixed in `7.6.5` / `8.6.6`.

## Evidence

**Advisory evidence:** `CVE-2026-59877` applies to `protobufjs` at installed version `7.6.2`. The advisory is fixed in `7.6.5`.

**Transitive dependency:** introduced by the direct dependency `@opentelemetry/sdk-node@0.218.0`.

**Dependency chain:** `@opentelemetry/sdk-node@0.218.0 > @opentelemetry/exporter-trace-otlp-grpc@0.218.0 > @grpc/grpc-js@1.14.4 > @grpc/proto-loader@0.8.0 > protobufjs@7.6.2`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct `protobufjs` import in src. Reached through `@opentelemetry/sdk-node` (direct dep; `src/otelBootstrap.ts` initializes the OpenTelemetry SDK). The affected-symbol (`Root.load`/`Root.loadSync` with attacker-controlled schema) check inside `@grpc/proto-loader` was not performed — schemas are normally static. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

A crafted `.proto` schema causes an infinite loop in the OTLP gRPC exporter's proto loading, hanging the Node.js event loop. Availability impact; requires a hostile schema to be loaded through the OpenTelemetry gRPC exporter path.

## Technical Analysis

**Root cause:** protobufjs < 7.6.5 / 8.6.6 loops indefinitely on a truncated option declaration. **Chain:** `@opentelemetry/sdk-node@0.218.0 > @opentelemetry/exporter-trace-otlp-grpc@0.218.0 > @grpc/grpc-js@1.14.4 > @grpc/proto-loader@0.8.0 > protobufjs@7.6.2`. **Trivy:** Severity=MEDIUM, CVSS nvd:7.5 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H), CWE-835.

## Remediation

Bump `@opentelemetry/sdk-node` / `@opentelemetry/auto-instrumentations-node` to a release whose closure resolves `protobufjs@>=7.6.5`, or `pnpm.overrides: { "protobufjs@7 <7.6.5": "^7.6.5" }`. Regenerate lockfile, verify with `trivy fs pnpm-lock.yaml`.

## Assumptions

Advisory from trivy-vendored NVD; web_search unavailable. Reachability `imported` via the OpenTelemetry SDK; exploitation needs a hostile .proto loaded through the gRPC proto-loader, which is unusual in practice. Trivy DB fresh (2026-08-18).
