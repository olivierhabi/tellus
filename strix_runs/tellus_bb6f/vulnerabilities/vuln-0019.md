## Description

The transitive package **`tar@7.5.13`** (via `duckdb`'s `@mapbox/node-pre-gyp`) is affected by CVE-2026-59875: a crafted archive with NUL bytes in metadata causes denial of service. Fixed in `7.5.17`.

## Evidence

**Advisory evidence:** `CVE-2026-59875` applies to `tar` at installed version `7.5.13`. The advisory is fixed in `7.5.17`.

**Transitive dependency:** introduced by the direct dependency `duckdb@1.4.4`.

**Dependency chain:** `duckdb@1.4.4 > @mapbox/node-pre-gyp@2.0.3 > tar@7.5.13`

**Usage analysis:** imported by application code; affected API usage unconfirmed. No direct `tar` import; reached only through duckdb > @mapbox/node-pre-gyp (src/services/furnaceSqlService.ts:55, src/services/duckdb/pool.ts:49 require duckdb). Affected-symbol check not performed. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

NUL bytes in archive metadata cause low-severity DoS in the duckdb binary-fetch path.

## Technical Analysis

**Root cause:** NUL-byte in metadata DoS in node-tar < 7.5.17. **Chain:** `duckdb@1.4.4 > @mapbox/node-pre-gyp@2.0.3 > tar@7.5.13`. **Trivy:** CVSS 5.3.

## Remediation

Resolve `tar@>=7.5.21` via `pnpm.overrides: { "tar@<7.5.21": "^7.5.21" }` or bump `duckdb`; regenerate lockfile; verify.

Advisory from trivy-vendored GHSA; web_search unavailable. Reachability `imported`. Trivy DB fresh (2026-08-18).
